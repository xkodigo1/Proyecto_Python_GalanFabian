# Proyecto_Python_GalanFabian
Desarrollo de un juego conocido The Chachipun, similar a piedra, papel o tijera.
__init__.py: Paquete que contiene cada módulo.
core.py: Esquema base similar a la estructura que llevó el JSON. 
custom.py: Funciones que podrian servir y/o usarse para el SO.
jcj.py: Código base del modo de juego "Jugador contra Jugador".
jve.py: Código base del modo de juego "Jugador contra Entorno".
menuP.py: Módulo principal donde se llaman las funciones de los dos modos de juego.

El objetivo en este juego es ganar tres rondas antes que el oponente. Cada ronda requiere tanto estrategia como suerte, ya que los jugadores intentan anticipar y contrarrestar las decisiones de su oponente. Aunque es sencillo, "The Cachipun" representa principios de teoría de juegos en los que la anticipación de las decisiones del oponente puede decidir el resultado final del juego. El primer jugador que gana tres rondas consecutivas es el ganador definitivo, poniendo fin a un juego que puede ser tanto rápido como intensamente competitivo.
